# runtime-tools

Pinned builds of runtime tools for application containers and CI.

Planned tools: MuPDF (`mutool`, with embedded MuJS) and FFmpeg (`ffmpeg` and
`ffprobe`), for Linux AMD64 and ARM64. Versioned GitHub releases will provide
precompiled archives, checksums, build metadata, licenses, and source materials.

Versions are updated explicitly and reviewed; consumers never install a floating
latest release. Build and release tooling is not implemented yet.
