# Implementation validation

Local validation on 2026-09-21, using Linux ARM64 under Colima on an ARM64 Mac.
These are development artifacts from an uncommitted tree; the release assembler
rejects them. Native CI is tracked in [PR #1](https://github.com/m4444l/runtime-tools/pull/1)
and its [initial run](https://github.com/m4444l/runtime-tools/actions/runs/35570114924).
The release workflow must pass separately before publication.

## Verified behavior

- Every locked upstream source downloaded and SHA256-verified; FFmpeg's detached
  signature verified against the committed signing key. The x264 Git archive has
  the same SHA256 when generated by host Git and Linux builder Git.
  Both extracted source bundles successfully locate and verify their bundled
  inputs without Git metadata or another download.
- MuPDF 1.28.4 with bundled MuJS builds offline. Extracted archives pass on Ubuntu
  24.04 and Debian 13, natively and under Cortex-A53 emulation: 33-class regexp,
  structured text/search, redaction, XML attachment retention, PNG rendering.
- FFmpeg 9.0.2 and ffprobe build offline from a fresh container with the pinned
  external libraries. Extracted
  archives pass both distributions, natively and under Cortex-A53 emulation:
  codec round trips, Rails preview/probe arguments, rotation, font diagnostics,
  and HTTPS system trust. Non-root text/subtitle rendering passes with distro
  fonts and a writable user cache. Untrusted certificates fail; adding the fixture
  CA to the system store succeeds without an explicit CA-file argument.
- Archive packaging rejects unexpected ELF dependencies, wrong architecture or
  interpreter, newer-than-baseline glibc symbols, and runtime build/data paths.
- Unit tests cover checksum failure before extraction, unsupported platforms,
  source-lock completeness, missing release inputs, tampered verified archives,
  rejection of builds from uncommitted changes, and successful release assembly:
  The original 7 tests / 125 assertions passed on host Ruby and Ubuntu's Ruby;
  release-report validation extends this to 143 assertions, passing locally.
  Workflow syntax
  passes actionlint; all 11 Ruby files pass syntax checks.

## Remaining validation before publication

AMD64 compilation on the ARM64 host failed inside QEMU with GCC `cc1`/`cc1plus`
segmentation faults in unrelated MuPDF and x265 translation units, including a
single-job retry. No AMD64 artifact was produced. This is a local emulation
limitation; it is not evidence that the native AMD64 recipe passes. Native
`ubuntu-24.04` CI must build and test it; ARM64 CI uses `ubuntu-24.04-arm`.

Repository protections are now configured: immutable releases, required native
CI and PRs on main, protected release tags, and a main-only release environment.
No draft has yet been created or consumer migrated. The release workflow must
still demonstrate cross-architecture source
bundle equality, repeat-build comparison, provenance, and draft creation after
human review. Bit-for-bit reproducibility is not claimed. Follow the first-release
prerequisites and deferred-decision checklist in [the runbook](releases.md).
